## Build

`compose.py` renders `entry.png` (PIL, local build only).
`main.py` is the stdlib-only carrier: it copies `entry.png` to the output
directory, byte for byte. Run it twice and the outputs are identical.

```
python3 compose.py            # renders entry.png (variant A, the duel winner)
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
